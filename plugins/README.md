# Plugin staging directory

This directory is the default plugin root used when the standalone host or the
embedded sample is started from the repository root.

It is generated by:

```powershell
./scripts/prepare-plugins.ps1 -Configuration Debug
```

The script builds `samples/HelloPlugin` and `samples/FailingPlugin`, then copies
each complete output directory into `plugins/<manifest-id>/`. Generated plugin
files are ignored by Git; only this README is tracked.

Each plugin installation has this shape:

```text
plugins/
  com.example.hello/
    plugin.json
    HelloPlugin.dll
    HelloPlugin.deps.json
    ModularRuntime.Contracts.dll
    ...
```
